# Desenvolvimento

Instale as dependências:
```
$ npm install
```
Para iniciar um serviço local:

```
$ npm run start:local
```

# Produção

Instale as dependências:

```
$ npm install
```
E, então, execute:

```
$ npm run build --prod
```
